# `Agent-I tui`

Open the terminal UI connected to the Gateway.

Related:

- TUI guide: [TUI](/web/tui)

## Examples

```bash
Agent-I tui
Agent-I tui --url ws://127.0.0.1:18789 --token <token>
Agent-I tui --session main --deliver
```
