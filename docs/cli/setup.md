# `Agent-I setup`

Initialize `~/.Agent-I/Agent-I.json` and the agent workspace.

Related:

- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
Agent-I setup
Agent-I setup --workspace ~/.Agent-I/workspace
```

To run the wizard via setup:

```bash
Agent-I setup --wizard
```
